# Repository Inventory

`zcsc` originated from the ZEAZ repository baseline and intentionally retains governance/AI-engineering controls. It is no longer a generic template repository.

## Product

- `apps/camfrog-status-changer/` — application core and app-specific documentation.

## Retained repository controls

- `.github/` — issue/PR templates, CodeQL, dependency review, Dependabot and CI.
- `scripts/` — repository validation/admin helpers.
- `AGENTS.md`, `CLAUDE.md`, `OPENCODE.md`, `ZEAZ-INTRODUCTION.md` — agent operating guidance.
- `skills/`, `components.d/`, `plugins.d/` — reusable ZEAZ execution/catalog metadata.

Retained baseline files are governance infrastructure, not the product identity.
